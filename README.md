# NEON JUMP · 赛博跳一跳

基于 Three.js 的网页端真 3D「跳一跳」，暗色赛博霓虹风格：近黑背景、发光描边的悬浮霓虹柱、随时间传播到你面前的配色循环。

## 运行

两种方式任选其一：

1. **直接双击打开** `index.html`（推荐，零依赖、零构建）。
2. **本地静态服务**（适合需要 http 环境的场景）：

```bash
# 任选其一
npx serve
python -m http.server 5173   # 然后访问 http://localhost:5173
```

> three.js 通过 CDN 加载（unpkg → jsDelivr → esm.sh 三级兜底），首次打开需要联网。若全部不可用，页面会显示加载失败提示。

## 玩法

| 操作 | 说明 |
| --- | --- |
| 按住 `空格`（或按住鼠标左键） | 开始蓄力，棋子被压扁、底部蓄力条增长 |
| 松开 | 按当前力度跳出对应距离的抛物线，空中翻转一圈 |
| 失败后按 `空格` | 重新开始（也可点击结算卡按钮） |

- 落在方块**中心区域**（距离中心 ≤ 0.26）：判定 `PERFECT`，触发连击，得分 `1 + 当前连击数`，屏幕中央弹出 combo 提示并炸开霓虹光波。
- 落在方块顶面但未达中心：得 1 分，连击清零。
- 落点没有任何方块：棋子坠入霓虹深渊，游戏结束，弹出结算面板（本局分数 / 连击上限 / 历史最高 / 是否破纪录）。
- 历史最高分保存在浏览器 `localStorage`（键名 `neonjump.best`）。

## 调参

所有玩法与视觉参数集中在 `index.html` 顶部的 `CFG` 常量区：

```js
const CFG = {
  block:   { size: 1.7, pillar: 18 },        // 顶面边长 / 柱体向下延伸长度
  gap:     { min: 2.3, max: 4.6 },           // 相邻方块中心间距（越大越难）
  top:     { min: -1.4, max: 1.6, jitter: 0.62 }, // 顶面高度范围与逐块抖动
  charge:  { speed: 1.05, minJump: 1.0, maxJump: 6.4 }, // 蓄力速度 / 跳跃距离区间
  jump:    { baseDur: 0.34, perUnit: 0.055, arcBase: 1.5, arcPerUnit: 0.22 }, // 滞空时间与弧线高度
  perfect: 0.26,      // PERFECT 判定半径，调大更容易连击
  window: 9,          // 场景中同时存在的方块数量（旧方块自动回收）
  gravity: 26,        // 坠落时的重力
};
```

常用调整：

- 想更简单：`perfect` 调到 `0.4`，`gap.max` 调到 `4.0`。
- 想更硬核：`gap.max` 调到 `5.2`，`charge.maxJump` 相应调到 `6.8`。
- 蓄力更慢更好控：`charge.speed` 调到 `0.85`（满蓄力约 1.2 秒）。
